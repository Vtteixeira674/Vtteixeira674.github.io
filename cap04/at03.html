Glossário de Termos

Entenda os termos mais utilizados no desenvolvimento web:

HTML
Linguagem de marcação usada para estruturar páginas web.
CSS
Linguagem utilizada para estilizar páginas HTML.
JavaScript
Linguagem de programação usada para adicionar interatividade às páginas.
DOM
Estrutura que representa os elementos de uma página HTML.
Interface que permite ao JavaScript manipular o conteúdo da página.
API
Conjunto de regras que permite comunicação entre sistemas.
Interface usada para integração entre aplicações.
HTTP
HyperText Transfer Protocol
Protocolo utilizado para transferência de dados na Web.
URL
Endereço Web
Localização de um recurso disponível na internet.
DNS
Sistema responsável por converter nomes de domínio em endereços IP.
Frontend
Parte visual de um site ou aplicação web.
